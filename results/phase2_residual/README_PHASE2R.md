# `results/phase2_residual/` — the residual-directionality diagnostic

These rows answer a different question from `results/phase2/`, against a
different null, and **must not be pooled with it**. Phase 2 asks "can a model
family predict `y(i→j)` for an unseen pair"; this asks "once the per-drug
ordering potential `g_i − g_j` has been removed with a model fitted on training
pairs only, can anything predict the remainder `D_res` for an unseen pair".
The metric columns are prefixed `heldout_` / `cal_` rather than Phase 2's
`test_` so that the two cannot be silently concatenated, and
`residual_report.load_residual_runs` raises if handed a Phase 2 file.

| file | what it is | rows |
|---|---|---|
| `runs.jsonl` | the main grid: 5 rungs × 5 coverages × 2 screens × 8 split seeds | 400 |
| `sensitivity.jsonl` | same, at the two decision coverages, with the ridge penalty chosen to *maximise* directional removal (`ridge_objective="D"`) | 160 |
| `controls.jsonl` | control A — `D_res` permuted across training and validation pairs, at coverages 0.10, 0.40 and 0.70 | 96 |
| `power.jsonl` | positive control — a known antisymmetric signal of RMS κ injected into `D`, **both screens**, both rungs, both κ | 320 |
| `power_honest_alpha.jsonl` | the same positive control under the shrinkage estimator the decision quotes (`lowrank` only) | 160 |
| `contaminated_diagnostic.jsonl` | control C — the additive baseline deliberately fitted on the held-out pairs. **Not a result.** Every row carries `contaminated: true` | 8 |
| `honest_alpha.jsonl` | the three rungs the primary contrast depends on, rerun with the shrinkage coefficient fitted on validation pairs withheld from model selection. **These are the numbers quoted in the decision**; see `docs/phase2_residual_directionality.md` §8.6 | 240 |
| `ridge_titration.jsonl` | control E — the additive penalty forced to λ ∈ {3, 30, 300} at coverage 0.70, so a known fraction of the potential is left in the residual. Establishes that the `potential` rung is a working detector rather than a dead one | 96 |
| `rank2.jsonl` | the low-rank rung pinned to rank 2 — 204 parameters, no hyperparameter search at all — because the searched grid selected its boundary rank at the cell that decides the result | 80 |
| `summary/` | regenerated by `scripts/report_phase2_residual.py`; tables, figures, `residual_summary.json` | — |
| `summary/doc_tables.md` | the markdown tables that must appear **verbatim** in `docs/phase2_residual_directionality.md`. Generated so they cannot drift; pinned by `test_document_tables_are_generated_not_transcribed` | — |

## Column groups

| prefix | meaning |
|---|---|
| `heldout_*` | metrics of the rung's raw prediction against `D_res` on the held-out pairs |
| `cal_*` | the same after a validation-selected shrinkage `α ∈ [0,1]`. **Primary.** |
| `raw_*` | metrics of `D_add + α·D̂_res` against the *raw* directional effect `D`, so the residual result can be put next to Phase 2's |
| `dec_*` | the additive decomposition on the held-out pairs — identical across rungs within a split seed, so it is read off the `zero` rows only |
| `split_*` | connectivity report for the split, unchanged from Phase 2 |

## Reproduction

```
python scripts/download_koplev.py                 # once
python scripts/run_phase2_residual.py --counts    # what each part costs, from the grids
python scripts/run_phase2_residual.py --part all  # 1,560 runs, ~2.5 h on 7 workers
python scripts/report_phase2_residual.py
```

`--part all` runs every block including `robustness`: main 400, sensitivity 160,
controls 104 (96 permutation + 8 contaminated), power 480 (320 + 160 honest-α),
robustness 416 (honest-α 240, rank-2 80, titration 96) — the same totals as the
`rows` column above. They are computed by `residual_sweep.part_counts()` from
the grid functions themselves and pinned to this file by
`test_documented_run_counts_match_the_grids`. An earlier version of this block
said 1,112, from before the permutation control was widened from two coverages
to three.

There is deliberately **no tuning stage**. Hyperparameters are selected inside
every run against that run's own validation pairs; a separate tuning stage that
reuses one setting across cells is what produced the Phase 2 fairness failure
recorded in `docs/phase2_koplev.md` §7.8.

The decision rule was pre-registered in `docs/PREREGISTRATIONS.md` and committed at
`995a166`, before the main grid was run. The analysis lives in
[`docs/phase2_residual_directionality.md`](../../docs/phase2_residual_directionality.md).
