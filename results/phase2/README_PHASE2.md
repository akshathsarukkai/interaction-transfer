# Phase 2 results index

Phase 1's index is `../README_RESULTS.md`. Phase 2 results live here and are
never pooled with Phase 1 rows: different data, different models, different
target.

**The authoritative file is `runs.jsonl`.** Everything in
`docs/phase2_koplev.md` and the README's Phase 2 section is computed from it by
`scripts/report_phase2.py`. Select rows by `tag`, then by
`(screen, coverage, family, split_seed, init_seed)`.

| file | rows | what it is |
|---|---|---|
| `runs.jsonl` | 448 | **authoritative.** Every experimental run: `tag` ∈ {`main` (320), `direction_shuffle` (64), `initvar` (64)}, all metrics, split connectivity, per-restart diagnostics, and the full resolved config. Reproduced by `run_phase2.py --part all`. |
| `tuning_parity.jsonl` | 192 | Both pair families across the learning-rate grid at four cells, so the family contrast can be recomputed with each family at its *own* validation-selected rate. `tag` = `parity_lr{rate}`. See `docs/phase2_koplev.md` §7.8. Reproduced by `run_phase2.py --part parity`. |
| `hparams.json` | — | The per-family hyperparameters used by every `main` run, and the grid they were chosen from. |
| `hparams.jsonl` | 144 | The selection sweep itself, at dev split seeds 100/101. **Not results** — these runs are inputs to a choice and must never be aggregated with `runs.jsonl`. |
| `dataset_audit.json` | — | Provenance, digests, the table-usability re-derivation, the publication-statistic reproduction, per-screen counts, and split connectivity at every coverage and seed. Generated by `scripts/prepare_koplev.py`. |
| `summary/main_table.json` | — | Per-(screen, coverage, family) mean/sd/n for every reported metric. |
| `summary/paired_deltas.json` | — | Paired contrasts with CIs, t and Wilcoxon p-values, paired on split seed. |
| `summary/collapse_diagnostics.csv` | — | Antisymmetric-collapse counts per family. Reported for every family, not only the structured one. |
| `summary/direction_shuffle_control.csv` | — | The control: schedule direction destroyed in training only. |
| `summary/runs.csv`, `summary/runs_by_split_seed.csv` | — | Flat views of `runs.jsonl` for spreadsheet inspection. |
| `summary/fig*.png` | — | The four figures. |
| `smoke.jsonl` | — | Output of `run_phase2.py --part smoke`. A pipeline check, not a result. Gitignored. |

## Aggregation rule

A run is one `(screen, coverage, family, split_seed, init_seed)`. **Init seeds
are averaged first, so the unit of every paired test is the split seed** — which
pairs happened to be observed. Treating two init seeds as two independent
observations would double the apparent `n` for free.

## Do not

* **Do not pool the two screens.** A375 and PANC1 are separate experiments on
  the same 100 drugs, reported separately throughout.
* **Do not aggregate `hparams.jsonl` with `runs.jsonl`.** The former is
  selection, at dev split seeds disjoint from the evaluation seeds.
* **Do not read `tag="direction_shuffle"` rows as results.** They are a control
  in which the training labels were deliberately corrupted.
